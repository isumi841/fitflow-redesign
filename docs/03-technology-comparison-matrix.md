# Activity 3 – Technology Comparison Matrix

| Component | Best Option | Key Finding |
|---|---|---|
| Frontend | React Native | High code reusability, fast development, strong AI/ML and real-time support, and web compatibility |
| Backend | Node.js / NestJS | Strong API and real-time performance with a large ecosystem |
| Database | PostgreSQL | Strong choice for structured health data, complex queries, relationships, and consistency |
| Authentication | Firebase Auth | Easy integration, secure authentication, real-time service compatibility, and low maintenance |
| AI Service | Python / FastAPI | Excellent AI/ML ecosystem for workout recommendation and nutrition analysis |
